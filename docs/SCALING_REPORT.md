## 5. 结论与建议

### 5.1 最佳配置

- **小规模网格**（< 256×256）：串行或 2 进程
- **中规模网格**（256×256 - 1024×1024）：4-8 进程
- **大规模网格**（> 1024×1024）：16-64 进程

### 5.2 优化建议

- [ ] 当子域 < 64×64 时，增加每进程网格或合并进程
- [ ] 启用通信-计算重叠（`--overlap-comm`）
- [ ] 使用 `numactl` 绑核
- [ ] 考虑使用 `MPI_Neighbor_allgather`（Collective 模式）
- [ ] 对于 3D 问题，优先使用 2D 进程拓扑（z 方向不分解）
